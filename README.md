# سپهر · Sepehr

استودیوی طالع‌بینی استوایی غربی با محاسبات واقعی **Swiss Ephemeris** (WASM). فارسی‌اول، راست‌به‌چپ.

- چارت تولد، ترانزیت، سینستری، کامپوزیت، بازگشت خورشیدی، پیشرفت ثانویه
- خانه‌ها: پلاسیدوس (پیش‌فرض)، کوخ، متساوی، کامل، کامپانوس، رجیومونتانوس
- گزارش سنتی (dignities، sect، ارباب خانه‌ها، الگوها) روی دادهٔ محاسبه‌شده — نه متن ساختگی

سایت روی Vercel دیپلوی می‌شود.
